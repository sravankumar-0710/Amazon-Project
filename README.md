# Amazon Clone

This is a beginner-level Amazon clone project that I built while learning HTML, CSS, and JavaScript.

The main goal of this project is to practice JavaScript by building a small e-commerce website instead of only doing separate coding exercises.

## Features

- Display products dynamically using JavaScript
- Product images, ratings, prices, and names
- Add products to the shopping cart
- Select product quantity
- Show cart item count
- Checkout page
- Update product quantity
- Remove products from cart
- Choose a delivery option
- Calculate delivery dates
- Store cart data using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Day.js
- LocalStorage
